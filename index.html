How it works

01
Type your message
Written only in your browser. Nothing leaves your device yet.
02
Encrypted locally
AES-256-GCM encryption runs entirely in your browser using the Web Crypto API.
03
Key in the URL
The cipher key is in the link's #fragment, which browsers never send to servers.
04
Server burn registry
Once revealed, a burn record is written to our server database. Every future open — any device, VPN, browser — is permanently blocked.
True one-time enforcement: Unlike localStorage-only approaches, GhostLink writes to a server-side database on first open. This means the burn state is global — no VPN, device change, browser switch, or cache clearing can bypass it.
